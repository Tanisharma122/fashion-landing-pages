# Fashion Landing Pages

Scroll-driven, interactive landing pages for fashion brands. Each page is a standalone portfolio demo built for a fictional brand.

## Pages

| Folder | Brand type | Style |
|---|---|---|
| `streetwear/` | Gen Z clothing label | Bold, fast and playful |
| `bridal-festive-wear/` | Premium bridal and festive ethnic wear | Elegant lookbook with a luxury feel |
| `tailored-suits/` | Made-to-measure suits and groomswear | Clean and refined, with a booking call to action |

## Structure

```
fashion-landing-pages/
├── streetwear/
├── bridal-festive-wear/
├── tailored-suits/
└── README.md
```

## Run a page

Open the folder's `index.html` in a browser, or serve it locally with a tool like Live Server.
